# AI 项目模板

## 0. 模板使用说明

本仓库提供用于 AI 辅助软件开发的项目规范与文档模板，不含业务代码或可执行环境配置。占位内容仅用于提示填写，不是已确认的项目事实，不得作为执行依据。

### 交给 AI 开始项目

1. Fork（派生仓库）后，将仓库克隆到本地，或放入 AI 工具可访问的工作区。已有项目可直接复制这五份文件，保留相对路径；同名文件先比较并合并，不直接覆盖。
2. 在目标项目根目录打开 AI 工具，明确要求它读取 `AGENTS.md`，并按入口要求读取相关文档。
3. 说明项目目标、本次实现范围和已有技术约束，然后发送下面的首次指令。无需提前手动填写全部文档；派生仓库本身不会自动启动 AI 工作。

将方括号内容替换为实际需求后发送：

```text
请读取并遵守仓库中的 AGENTS.md，初始化这个项目。

项目目标：[解决什么问题、面向谁]
本次实现范围：[首批功能及明确不做的内容]
技术栈与约束：[已有要求；尚未确定时，请推荐最简单可行方案并说明取舍]

先检查已有文件，按 README 的“适配步骤”完成文档适配，再完成上述范围所需的本地项目初始化。
影响实现的关键缺失信息先询问，其余按最简单可行方案处理；未核查的信息标记“待确认”。
环境与外部连接未确认前，不执行依赖这些条件的操作。不要提交、推送或发布。
完成后说明实际修改、验证结果和仍需我提供的信息。
```

适配完成后，应能从 README 找到项目用途、实际目录、可用命令及环境限制，从 `docs/CURRENT_STATE.md` 区分已实现内容与待验证事项。后续直接提出具体开发任务即可。

### 适配步骤

以下步骤可由 AI 执行，也可人工完成。

1. 核查目标项目已有源码、配置和文档，保留已有有效内容。
2. 填写本文件的项目介绍、模块、环境、命令与发布信息。命令必须来自真实项目，不从其他项目照搬。
3. 根据已确认实现填写 `docs/CURRENT_STATE.md`。未核查部分保留“待确认”，没有业务代码时如实写“尚未实现”。
4. 保留两份专项规范的通用部分，在项目专属部分填写技术约束；没有额外规则时明确写“暂无”。
5. 检查 `AGENTS.md` 的任务入口与安全边界，按已确认项目要求调整，不移除尚有必要的保护。
6. 有正式需求时再创建可选文档，并记录到本文件的文档导航。没有需求时不创建空目录。
7. 完成适配后，将本文件标题改为实际项目名称，删除第 0 节，并清理五份文件中的模板身份声明和已完成的填写提示。未核查事项明确标记“待确认”，保留有效规则及项目自己的介绍、目录、命令和导航。

“独立使用”表示必要规范保存在项目中，不需要复制个人全局规则；它不保证任意 AI 工具都自动加载这些文件，也不提供运行环境、工具权限或凭据。

使用 Codex 时，应在目标项目启动新任务，并确认实际加载的指令来源；修改 `AGENTS.md` 后不能仅凭文件已保存断言当前会话已重新加载。专项文件由入口规则要求按任务读取。其他 AI 工具按其实际支持的方式引用规则，不默认安装额外配置。

规则加载说明核对自 [OpenAI 官方 AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

### 推荐目录

```text
项目根目录/
├── AGENTS.md                      必备：AI 入口、权限、安全与验收
├── README.md                      必备：项目介绍、环境、命令与文档导航
├── PROJECT_PLAN.md                可选：项目目标、阶段与验收标准
├── docs/
│   ├── ENGINEERING_RULES.md        必备：通用工程规范与项目专属规则
│   ├── WRITING_RULES.md            必备：表达、文档职责与维护规则
│   ├── CURRENT_STATE.md            必备：当前实际状态与重要限制
│   ├── contracts/                 可选：正式业务与数据契约
│   ├── api/                       可选：正式接口契约
│   ├── design/                    可选：已确认专项设计
│   ├── audits/                    可选：有日期、有范围的审查结果
│   └── archive/                   可选：已失效的历史文档
└── 项目自己的业务代码目录          不由本模板规定
```

上图包含可选位置，当前模板只创建五份必备文件。可选文档按实际需要和 `docs/WRITING_RULES.md` 的文档职责、更新条件创建；这里仅提供目录导航。

不默认增加固定语言目录、模型配置、代理编排程序、任务日志或持续集成配置。它们属于具体项目需求，不属于本模板必备内容。
