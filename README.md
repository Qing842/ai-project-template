# [待填写：项目名称]

> 本目录提供可复制的项目 AI 规范与文档模板，不含业务代码、可执行环境配置或秘密。
> `[待填写：…]` 是适配提示，不是已确认的项目事实。未填写内容不得作为执行依据。

## 0. 模板使用说明

### 复制与适配

1. 将本目录中的五份文件复制到目标项目，保留相对路径。目标已有同名文件时先比较并合并，禁止直接覆盖。
2. 填写本文件的项目介绍、模块、环境、命令与发布信息。命令必须来自真实项目，不从其他项目照搬。
3. 根据已确认实现填写 `docs/CURRENT_STATE.md`。未核查部分保留“待确认”，没有业务代码时如实写“尚未实现”。
4. 保留两份专项规范的通用部分，在项目专属部分填写技术约束；没有额外规则时明确写“暂无”。
5. 检查 `AGENTS.md` 的任务入口与安全边界，按已确认项目要求调整，不移除尚有必要的保护。
6. 有正式需求时再创建可选文档，并记录到本文件的文档导航。没有需求时不创建空目录。
7. 完成适配后删除本文件第 0 节和已经替换的占位提示，保留项目自己的介绍、目录、命令和导航。

“独立使用”表示必要规范保存在项目中，不需要复制个人全局规则；它不保证任意 AI 工具都自动加载这些文件，也不提供运行环境、工具权限或凭据。

使用 Codex 时，应在目标项目启动新任务，并确认实际加载的指令来源；修改 `AGENTS.md` 后不能仅凭文件已保存断言当前会话已重新加载。专项文件由入口规则要求按任务读取。其他 AI 工具按其实际支持的方式引用规则，不默认安装额外配置。

规则加载说明核对自 [OpenAI 官方 AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

### 推荐目录

```text
项目根目录/
├── AGENTS.md                      必备：AI 入口、权限、安全与验收
├── README.md                      必备：项目介绍、环境、命令与文档导航
├── PROJECT_PLAN.md                可选：项目目标、阶段与验收标准
├── docs/
│   ├── ENGINEERING_RULES.md        必备：通用工程规范与项目专属规则
│   ├── WRITING_RULES.md            必备：表达、文档职责与维护规则
│   ├── CURRENT_STATE.md            必备：当前实际状态与重要限制
│   ├── contracts/                 可选：正式业务与数据契约
│   ├── api/                       可选：正式接口契约
│   ├── design/                    可选：已确认专项设计
│   ├── audits/                    可选：有日期、有范围的审查结果
│   └── archive/                   可选：已失效的历史文档
└── 项目自己的业务代码目录          不由本模板规定
```

上图包含可选位置，当前模板只创建五份必备文件。文档的维护规则与职责唯一维护在 `docs/WRITING_RULES.md`；这里仅提供目录导航。

### 可选文档的创建条件

| 位置 | 何时增加 |
| --- | --- |
| `PROJECT_PLAN.md` | 需要明确多阶段目标、项目范围或项目级验收标准 |
| `docs/contracts/` | 已确认的业务或数据规则需要跨模块引用、测试或协作 |
| `docs/api/` | 接口需要被前后端、第三方或自动化检查共同遵守 |
| `docs/design/` | 专项技术决策已确认，需要明确边界、依赖与验收标准 |
| `docs/audits/` | 需要保存阶段验收、发布前审查或重大风险核查证据 |
| `docs/archive/` | 文档已失效，但确有历史参考价值且需要保留 |

不默认增加固定语言目录、模型配置、代理编排程序、任务日志或持续集成配置。它们属于具体项目需求，不属于本模板必备内容。
